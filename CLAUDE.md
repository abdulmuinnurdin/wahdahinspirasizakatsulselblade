# Project: Wahdah inspirasi zakat (Portal)

## Skill wajib
- SELALU Gunakan SKILL `./.claude/skills/laravel-best-practices-1.0.6-v1` sebelum menulis kode.
- Untuk setiap task yang menyentuh kode backend (endpoint, service, repository, model, FormRequest, query), WAJIB baca dan terapkan `./.claude/skills/msd-laravel-folder/SKILL.md`, dan kode (log) sesuai skill `./.claude/skills/msd-laravel-logging/SKILL.md` sebelum menulis kode.
- Untuk setiap task membuat API, WAJIB baca dan terapkan `./.claude/skills/msd-laravel-jsonapi/SKILL.md` sebelum menulis kode.
- Untuk setiap task membuat atau mengubah test (Unit/Feature), WAJIB baca dan terapkan `./.claude/skills/msd-laravel-testing/SKILL.md` sebelum menulis kode.
- Untuk setiap task membuat atau mengubah halaman admin Blade (form + tabel CRUD, icon, toast/notifikasi), WAJIB baca dan terapkan `./.claude/skills/msd-laravel-admin-ui/SKILL.md` sebelum menulis kode.
- Untuk setiap task yang melakukan lebih dari satu insert/update/delete yang harus atomic (DB transaction, rollback, deadlock, retry), WAJIB baca dan terapkan `./.claude/skills/msd-laravel-db-transaction/SKILL.md` sebelum menulis kode.
- Untuk setiap task yang mengubah data sensitif (saldo, kuota, stok) yang bisa diakses bersamaan, WAJIB baca dan terapkan `./.claude/skills/msd-laravel-row-locking/SKILL.md` sebelum menulis kode.
- Untuk setiap task membuat endpoint API yang bisa dipanggil berulang oleh bot/client otomatis (rate limit, throttle, queue job berat seperti email/notifikasi), WAJIB baca dan terapkan `./.claude/skills/msd-laravel-rate-limiting/SKILL.md` sebelum menulis kode.
- Untuk setiap task membuat endpoint POST/create yang insert data (idempotency key, cegah duplicate dari retry), WAJIB baca dan terapkan `./.claude/skills/msd-laravel-idempotency/SKILL.md` sebelum menulis kode.
- Untuk setiap task membuat job queue yang menyentuh resource yang bisa didispatch dobel (ShouldBeUnique, unique job), WAJIB baca dan terapkan `./.claude/skills/msd-laravel-queue-uniqueness/SKILL.md` sebelum menulis kode.
- Untuk setiap task membuat fitur import/insert data dalam jumlah banyak (bulk insert, chunking), WAJIB baca dan terapkan `./.claude/skills/msd-laravel-bulk-insert/SKILL.md` sebelum menulis kode.
- Untuk setiap task membuat job/command deteksi drift data finansial (rekonsiliasi saldo), WAJIB baca dan terapkan `./.claude/skills/msd-laravel-balance-reconciliation/SKILL.md` sebelum menulis kode.
- Untuk setiap task membuat/mengubah halaman Blade (view, layout, partial, component) atau teks yang tampil ke user, WAJIB baca dan terapkan `./.claude/skills/msd-laravel-i18n/SKILL.md` sebelum menulis kode.
- Di awal jawaban, sebutkan skill yang dipakai.
