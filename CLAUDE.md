# Project: Wahdah inspirasi zakat (Portal)

## Skill wajib
- SELALU Gunakan SKILL `./.claude/skills/laravel-best-practices-1.0.6-v1` sebelum menulis kode.
- Untuk setiap task yang menyentuh kode backend (endpoint, service, repository, model, FormRequest, query), WAJIB baca dan terapkan `./.claude/skills/msd-laravel-folder/SKILL.md`, dan kode (log) sesuai skill `./.claude/skills/msd-laravel-logging/SKILL.md` sebelum menulis kode.
- Untuk setiap task membuat API, WAJIB baca dan terapkan `./.claude/skills/msd-laravel-jsonapi/SKILL.md` sebelum menulis kode.
- Untuk setiap task membuat atau mengubah test (Unit/Feature), WAJIB baca dan terapkan `./.claude/skills/msd-laravel-testing/SKILL.md` sebelum menulis kode.
- Di awal jawaban, sebutkan skill yang dipakai.
